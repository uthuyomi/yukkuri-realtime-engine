計測値の定義

サーバー値はイベント生成時刻の差です。EOTは input_audio.turn の complete（サーバー発話確定通知）を起点とします。

STT: EOT → final通知。LLM: final通知 → 最初のtext delta。Server TTFA: EOT → 最初のaudio chunk開始通知（合成後）。TTS開始時刻は公開されていないため、TTSの内訳は未計測です。

Client TTFAはEOT通知受信 → 最初のPCM受信。実際の可聴開始ではありません。Audible TTFAは未計測です。割り込みは同じinterruption IDのsuspected → confirmed通知です。

totalはEOT → 生成終了通知。テキスト入力ではgeneration.createdが起点です。再生完了時間ではありません。— は未計測または対象外。表示のみ丸め、内部値は保持します。

実行環境について

リポジトリのルートをlocalhostのHTTPサーバーで配信してください。SDKのbuild、Engine、SmartTurn、STT、LLM、TTSが必要です。この例はSilero / ONNXを固定バージョンのCDNから取得します。履歴はページ内のメモリにのみ保持し、再読み込みで消去されます。
