# @yukkuri-realtime/client

Public API v1 SDK for modern browsers and Node.js 22+. ESM with TypeScript declarations, no runtime dependencies.

```sh
cd sdk/typescript
npm ci
npm run build
```

Install this directory from your application with `npm install /path/to/repo/sdk/typescript`.
See [TypeScript SDK](../../docs/typescript-sdk.md). The optional `/browser` entry owns microphone and render-progress playback integration.
